# MecaGest

Sistema académico de gestión de servicios para talleres mecánicos. Entrega del Criterio 2 del RdA1: monolito en capas, API OpenAPI, pruebas automatizadas y bitácora.

En construcción. Requiere Node.js 24. Los flujos acordados son ingreso, diagnóstico, autorización, reparación e historial.

La implementación se prepara con asistencia de Codex/ChatGPT. El equipo debe revisar el código, comprender sus decisiones y validar las reglas propuestas con un taller; no se presentan entrevistas ni mediciones de campo ficticias.
